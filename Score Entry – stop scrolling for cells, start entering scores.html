Set up once, then just keep entering

  1. Load your file and sheet

    Click Load Excel File and choose your .xlsx or .xls, then pick the sheet.

  2. Set up the columns

    Enter the headings row number, choose the column to search by (like RegNo) and the column the scores go into (like T1 or SE).

  3. Search and select

    Type a reg number and the matching record appears. Press Enter or Tab to select it.

  4. Type the score, press Enter

    The score is saved straight into the Excel file. Your last entry stays on screen so you can check it.

Good to know before you start

Close Excel first

If the file is open in Excel, the app cannot save to it and shows a permission error. Close it and try again.

Avoid merged cells

Keep merged cells out of the header row and the data area, or the app will show a merged cell error.

Search not finding anything?

Check that you chose the right search column and typed the value exactly as it appears in the sheet.
